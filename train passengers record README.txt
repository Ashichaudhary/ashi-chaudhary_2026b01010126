PROJECT TITLE: Train Passenger Record – Data Cleaning and Representation
Using Python

1.  INTRODUCTION This project focuses on working with a Train Passenger
    Record dataset using Python. The dataset is downloaded from Kaggle
    and processed using Google Colab.

2.  OBJECTIVES

-   To understand the train passenger dataset.
-   To perform data cleaning.
-   To identify and handle missing and NULL values.
-   To identify and remove duplicate records.
-   To perform data representation.

3.  TOOLS AND TECHNOLOGIES

-   Python
-   Google Colab
-   Pandas
-   NumPy
-   Kaggle
-   GitHub

4.  DATASET The dataset is downloaded from Kaggle in CSV format and
    uploaded to Google Colab for processing.

5.  DATA CLEANING The following operations are performed:

-   Checking missing values.
-   Identifying NULL values.
-   Handling missing values.
-   Removing duplicate records.
-   Checking data types.
-   Correcting inconsistent data.

6.  DATA REPRESENTATION The dataset is represented in a structured
    format using Python and Pandas.

7.  PLATFORM AND STORAGE Google Colab is used to write and execute
    Python code. GitHub is used to upload and store the project files.

8.  CONCLUSION This project provides practical knowledge of Python,
    dataset handling, data cleaning and data representation using a
    real-world dataset.
